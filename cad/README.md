# CAD

STEP assemblies for Fusion 360 / SolidWorks. Use these with the photos in [instructions](../instructions.md) if extrusion lengths or printed brackets are unclear.

| File | Contents |
|---|---|
| [`Extrusions.step`](Extrusions.step) | 1515 subframe (eight 200 mm lengths) |
| [`Hardware.step`](Hardware.step) | PETG skins, mounts, fasteners as-assembled |
| [`Electronics.step`](Electronics.step) | PSU, drivers, Uno/shield, pendant, fans in the cage |
| [`Fan_Grill_Parts.step`](Fan_Grill_Parts.step) | Thermoform mold and grill mesh for the 4010 openings |

Export format is STEP AP214/AP203 as received. Units millimetres.
